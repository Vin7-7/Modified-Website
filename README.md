# Atlas — Website Redesign Challenge

A responsive concept redesign of Wikipedia's discovery experience, reimagined as **Atlas**.

## Original website
https://www.wikipedia.org/

## What's included
- Responsive landing page with custom visual identity
- Search box that opens Wikipedia search results
- Quick-search chips
- Four topic cards linking to Wikipedia portals
- Daily random-article discovery link
- Light/dark theme toggle
- Mobile layouts, hover states, reduced-motion support
- No build tools or dependencies required

## Run locally
Open `index.html` in a browser.

## Publish with Vercel
1. Extract this ZIP.
2. Create a new public GitHub repository (for example `atlas-wikipedia-redesign`).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. In Vercel, choose **Add New → Project**, import that repository, and deploy with the default settings. No framework or build command is needed.
5. Copy the live deployment URL for the challenge submission.
